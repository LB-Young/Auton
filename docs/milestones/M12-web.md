## 前端交付

本里程碑交付完整主工作台；参考 frontend-design.md，后续新模块仍须增量交付各自页面。页面遵循 [前端规格](./frontend-design.md)，具备加载、空、失败、不可用与权限不足状态。

## 验收条件

1. 真实任务从新建到审批、工具、产物、刷新恢复可完整操作。
2. 断线、长输出、长列表、失败/空数据/权限不足有可用界面，窄屏无主要横向溢出。
3. HTML/Markdown/附件预览无法读取任意本地路径或执行未授权脚本；浏览器不持有 provider key。

## 必验故障

输入法误发送、流式输出抢滚动、重复消息、迟到批准、恶意 HTML、路由刷新失效。针对行为做契约/集成或端到端验证，交付可复现步骤与结果。
