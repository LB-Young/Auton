# M09：单 Agent 运行时与任务状态机

> 状态：计划中。当前仅建立开发计划，未实现本里程碑。

## 目标与前置依赖

在已有工厂模块上完成第一个真实单 Agent 任务闭环。

前置：M05、M06、M08。M01 必须先完成；其余按依赖验收后进入。

## 模块与工厂

AgentRuntimeFactory、SessionFactory、RunFactory。对外 Port、配置、实现选择、依赖注入与生命周期遵守 [工厂规范](./module-factory-contract.md)，调用方不得依赖具体 adapter。

## 开发任务

- [ ] 实现装配→调用模型→校验动作→执行工具→记录→继续/交付的受控循环。
- [ ] 定义 queued/running/waiting_approval/blocked/cancelling/cancelled/succeeded/failed 等状态与合法转移。
- [ ] 支持用户修订、暂停/取消、安全 checkpoint 和总预算；停止应由运行时确认。
- [ ] CLI 通过同一应用 Port 创建/恢复任务，记录所有真实模型/工具/判断来源；业务验收与模型自述分离。

## 前端交付

对话接入真实执行状态、工具卡片、停止确认、阻塞与最终产物；保留明确 Demo 环境。页面遵循 [前端规格](./frontend-design.md)，具备加载、空、失败、不可用与权限不足状态。

## 验收条件

1. 完成一个受控文件任务与一个只读调研任务，交付真实 artifact 和验收结果。
2. 取消后不继续发新动作；未知外部写先对账再恢复，旧版本结果不覆盖新目标。
3. agent 不 import learning/assess/evolve 实现；所有模块经工厂注入。

## 必验故障

无限循环、目标修订、模型断流、重复命令、工具未知结果、取消与完成竞态。针对行为做契约/集成或端到端验证，交付可复现步骤与结果。

## 范围与完成证据

先单 Agent；不要在基础循环尚不稳定时加入多 Agent 调度。

交付实现、相关检查结果、接口/配置/迁移说明和页面演示；由验收证据更新 [总表](./README.md)，不以 Mock 通过替代真实模块完成。
