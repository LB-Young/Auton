# M11：服务端 API、命令与事件流

> 状态：计划中。当前仅建立开发计划，未实现本里程碑。

## 目标与前置依赖

将 M01 API 骨架完善为稳定的 Web/CLI 共享服务接口。

前置：M03、M09、M10。M01 必须先完成；其余按依赖验收后进入。

## 模块与工厂

ServerFactory、CommandHandlerFactory、EventStreamFactory。对外 Port、配置、实现选择、依赖注入与生命周期遵守 [工厂规范](./module-factory-contract.md)，调用方不得依赖具体 adapter。

## 开发任务

- [ ] 固化项目、会话、run、artifact、审批、能力查询和命令 API，生成前端类型。
- [ ] HTTP 命令带 request_id/goal_revision；鉴权、来源校验、错误模型和并发冲突在服务端处理。
- [ ] WebSocket 明确持久游标、临时 delta、快照对齐、去重与重连，不能承诺 token 全部持久化。
- [ ] 实现上传限制、artifact 授权读取、资源清理、请求取消语义及后台任务与连接生命周期分离。

## 前端交付

前端统一使用真实 transport、连接/重连提示、加载与错误状态。页面遵循 [前端规格](./frontend-design.md)，具备加载、空、失败、不可用与权限不足状态。

## 验收条件

1. 浏览器断开不取消服务端任务；重连后正确恢复状态且不重复命令。
2. 未授权项目/文件和过期审批被服务端拒绝，前端绕过按钮也无效。
3. API schema 与生成类型一致，真实失败不会退回 Demo 数据。

## 必验故障

跨源请求、慢消费者、连接断流、重复提交、消息乱序、过期上传/审批。针对行为做契约/集成或端到端验证，交付可复现步骤与结果。

## 范围与完成证据

扩展 IM 客户端留后续；本里程碑不启用公网部署。

交付实现、相关检查结果、接口/配置/迁移说明和页面演示；由验收证据更新 [总表](./README.md)，不以 Mock 通过替代真实模块完成。
