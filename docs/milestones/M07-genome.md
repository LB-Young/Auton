# M07：资产、项目资料与记忆治理

> 状态：计划中。当前仅建立开发计划，未实现本里程碑。

## 目标与前置依赖

提供版本化 Skill/Prompt/role/知识与项目资料，建立可追踪的使用快照。

前置：M02、M03。M01 必须先完成；其余按依赖验收后进入。

## 模块与工厂

GenomeFactory、AssetRepositoryFactory、MemoryPolicyFactory、ResolverFactory。对外 Port、配置、实现选择、依赖注入与生命周期遵守 [工厂规范](./module-factory-contract.md)，调用方不得依赖具体 adapter。

## 开发任务

- [ ] 实现 git-backed 资产格式、schema、版本与来源；注册项目边界、资料引用和项目说明。
- [ ] Resolver 按固定规则返回不可变 snapshot，记录 AssetUsed 与适用范围；不能任意混入别的项目资料。
- [ ] 建立 learning 候选、晋升/冲突/过期/删除的治理接口；用户显式记忆与推断记忆来源分开。
- [ ] 只有受限写入/发布 Port 可修改正式资产；读取任务不能直接改 main。

## 前端交付

项目资料与说明页面、资产列表/版本/来源/差异和待晋升记忆视图。页面遵循 [前端规格](./frontend-design.md)，具备加载、空、失败、不可用与权限不足状态。

## 验收条件

1. 同一 snapshot 可复现；历史版本能查看和回退，来源与项目权限可追踪。
2. 错误 schema、冲突资产与过期记录有明确处置；删除沿索引和派生引用传播。
3. 外部 Skill 作为不可信输入，不获得额外工具权限。

## 必验故障

跨项目泄漏、同名冲突、误合并、并发写入、撤回后仍被检索。针对行为做契约/集成或端到端验证，交付可复现步骤与结果。

## 范围与完成证据

先人工管理与固定治理规则；自动 Skill/Prompt 优化留 M15。

交付实现、相关检查结果、接口/配置/迁移说明和页面演示；由验收证据更新 [总表](./README.md)，不以 Mock 通过替代真实模块完成。
