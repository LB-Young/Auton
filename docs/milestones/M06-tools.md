# M06：工具宿主、执行隔离与操作账本

> 状态：当前受控工具范围已完成本地验收，见 [M06 验收与隔离限制](./evidence/M06.md)。任意程序/远程插件尚未开放。

## 目标与前置依赖

以明确权限和幂等边界执行工具，优先解决重复副作用与未知执行结果。

前置：M02、M03。M01 必须先完成；其余按依赖验收后进入。

## 模块与工厂

ToolHostFactory、ToolAdapterFactory、SandboxFactory、OperationLedgerFactory。对外 Port、配置、实现选择、依赖注入与生命周期遵守 [工厂规范](./module-factory-contract.md)，调用方不得依赖具体 adapter。

## 开发任务

- [x] 统一 tool schema、发现/调用/结果契约；已提供受控文件读写、固定程序执行与一个真实本地 MCP 适配器。
- [x] 执行前校验路径、权限、预算和批准；首期隔离等级明确说明，不能把子进程称完整安全沙箱。
- [x] 建立 Operation Ledger：逻辑 operation_id、attempt、receipt、unknown 与对账接口。
- [x] 实现 artifact 注册、路径授权和原始工具错误分类；输出按不可信输入处理。

## 前端交付

工具卡片、审批卡、文件/差异预览和真实执行 receipt；未知结果显示待对账。页面遵循 [前端规格](./frontend-design.md)，具备加载、空、失败、不可用与权限不足状态。

## 验收条件

1. 可只读的任务不能写入；越界路径、过期审批和取消后新动作被拒绝。
2. 外部写超时先对账，不盲重放；重复命令不会产生两个逻辑操作。
3. 工具结果、artifact 和 receipt 可追溯，模型文字不能覆盖实际失败。

## 必验故障

路径穿越、符号链接越界、写成功但响应丢失、进程退出、恶意工具输出。针对行为做契约/集成或端到端验证，交付可复现步骤与结果。

## 范围与完成证据

不开放任意远程插件或共享云凭据；浏览器等后续适配按同契约增量加入。

交付实现、相关检查结果、接口/配置/迁移说明和页面演示；由验收证据更新 [总表](./README.md)，不以 Mock 通过替代真实模块完成。
