# M21：后台调度、运行监控与长期验证

> 状态：计划中。当前仅建立开发计划，未实现本里程碑。

## 目标与前置依赖

将已验证的学习与进化串成可控常驻流程，持续观测真实收益与故障。

前置：M10、M15、M17、M18/M19、M20。M01 必须先完成；其余按依赖验收后进入。

## 模块与工厂

SchedulerFactory、JobQueueFactory、TelemetryFactory、RetentionPolicyFactory。对外 Port、配置、实现选择、依赖注入与生命周期遵守 [工厂规范](./module-factory-contract.md)，调用方不得依赖具体 adapter。

## 开发任务

- [ ] 实现快/中/慢回路的资源窗口、优先级、幂等任务、租约、重试/退避、取消与停机恢复。
- [ ] 前台优先，后台 review/数据/训练不得抢占必要资源；达到新增数据/漂移门槛才训练。
- [ ] 统一成本、故障、方向指标与保留/删除任务，告警只在有实质变化或需介入时发送。
- [ ] 做备份恢复、重启、长会话、长期任务流、连续学习回归与回滚演练，形成运维说明。

## 前端交付

后台队列、资源窗口、任务健康、历史趋势、告警与暂停/恢复；主对话不刷运维日志。页面遵循 [前端规格](./frontend-design.md)，具备加载、空、失败、不可用与权限不足状态。

## 验收条件

1. 进程重启不重复训练或发布，worker 失联可恢复且不会双重执行。
2. 空闲训练在前台资源紧张时按策略暂停/排队，监控能说明原因。
3. 长期运行能定位收益/退化、删除影响与审查积压，不靠未验证自动化持续晋升。

## 必验故障

重复调度、租约过期双 worker、备份损坏、数据堆积、前台被饿死、方向长期漂移。针对行为做契约/集成或端到端验证，交付可复现步骤与结果。

## 范围与完成证据

后续 ToolSmith/复杂搜索策略/外部研究需另按模块和收益规划，不默认开启所有自进化。

交付实现、相关检查结果、接口/配置/迁移说明和页面演示；由验收证据更新 [总表](./README.md)，不以 Mock 通过替代真实模块完成。
