# M18：本地执行模型训练

> 状态：计划中。当前仅建立开发计划，未实现本里程碑。

## 目标与前置依赖

先在一个可验证任务域改善本地执行模型，训练产物只登记为候选。

前置：M04、M13、M17。M01 必须先完成；其余按依赖验收后进入。

## 模块与工厂

ExecutorTrainingFactory、TrainingBackendFactory、TrainingJobFactory。对外 Port、配置、实现选择、依赖注入与生命周期遵守 [工厂规范](./module-factory-contract.md)，调用方不得依赖具体 adapter。

## 开发任务

- [ ] 核对硬件与训练后端、base/tokenizer/template，先测未训练基线，再做 SFT/adapter 小规模实验。
- [ ] 检查对话/工具格式、目标 mask、长序列截断；保留旧任务 replay 与通用锚点。
- [ ] 训练作业有幂等 ID、预算、进度、取消、checkpoint、恢复与失败记录；不直接覆盖运行权重。
- [ ] 评测真实量化部署、工具协议、任务质量、遗忘与总成本，登记不可变 bundle 和 lineage。

## 前端交付

执行模型训练计划、资源/数据快照、job 状态、日志摘要和能力对照。页面遵循 [前端规格](./frontend-design.md)，具备加载、空、失败、不可用与权限不足状态。

## 验收条件

1. 同一数据与配置可复现并恢复训练，失败不触发重复昂贵 job。
2. 受限任务实际改善且旧任务不越回归门槛；loss 下降不是唯一验收。
3. 训练 worker 拿不到 provider secrets、受保护 test 或生产工具写权限。

## 必验故障

OOM、磁盘不足、取消后残留进程、格式错误、量化退化、checkpoint 损坏。针对行为做契约/集成或端到端验证，交付可复现步骤与结果。

## 范围与完成证据

不默认上在线 RL；不自动发布执行候选，M20 才激活。

交付实现、相关检查结果、接口/配置/迁移说明和页面演示；由验收证据更新 [总表](./README.md)，不以 Mock 通过替代真实模块完成。
