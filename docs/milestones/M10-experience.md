# M10：轨迹投影、检查点与恢复

> 状态：计划中。当前仅建立开发计划，未实现本里程碑。

## 目标与前置依赖

把事件转成可查询、可归因和可恢复的会话/任务/操作轨迹。

前置：M02、M09。M01 必须先完成；其余按依赖验收后进入。

## 模块与工厂

ExperienceFactory、ProjectionFactory、CheckpointRepositoryFactory。对外 Port、配置、实现选择、依赖注入与生命周期遵守 [工厂规范](./module-factory-contract.md)，调用方不得依赖具体 adapter。

## 开发任务

- [ ] 实现 session/goal/run/episode 投影与处理游标，重复消费幂等，支持重建与版本迁移。
- [ ] 建立判断→policy action→工具/模型调用→验收的引用关系，预留多 Agent DAG 关联。
- [ ] 持久 checkpoint 保存状态引用、输入截止点、预算、资产版本和未决操作，不只保存对话摘要。
- [ ] 查询按项目与用途权限裁剪；指标区分事件时间、处理时间、迟到结果与缺失数据。

## 前端交付

任务时间线、恢复入口、成本摘要与可展开轨迹；恢复页面刷新后仍与服务端一致。页面遵循 [前端规格](./frontend-design.md)，具备加载、空、失败、不可用与权限不足状态。

## 验收条件

1. 删掉可重建投影后从 EventLog 恢复得到一致查询结果。
2. 进程重启可在安全点继续，不重放已确认副作用。
3. 每个结果能定位具体判断/执行版本；缺证据明确显示未知。

## 必验故障

消费中断、重复事件、投影落后、目标并行修订、缺 snapshot、checkpoint 版本不兼容。针对行为做契约/集成或端到端验证，交付可复现步骤与结果。

## 范围与完成证据

不把投影分数当评测真值；独立评估在 M13。

交付实现、相关检查结果、接口/配置/迁移说明和页面演示；由验收证据更新 [总表](./README.md)，不以 Mock 通过替代真实模块完成。
