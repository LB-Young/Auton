# 当前模型接入选择

> 2026-11-17 用户明确修订。此记录更新接入选择，不表示 M04/M05 已实现。

- **M04 执行模型先接 DeepSeek**。凭据通过本机 `.env` 的 `DEEPSEEK_API_KEY` 引用，文件被 Git 忽略且权限为 0600。公开配置、接口、日志和测试不得包含值。实际模型版本、能力与费用在接入时核实。
- **M05 当前主判断模型改为本地 Laya**。先下载相容权重并验证中文/类型化判断；没有 Jev 凭据时不伪造托管 Jev 调用。
- 这是用户指定的主 provider 变更，不是 Jev/本地按难度或信心自动路由。困难/简单任务的执行模型选择与判断来源选择仍分开。
- 每次记录真实 provider、checkpoint、问题、选项与分数/置信度，不把 Laya 结果标成 Jev 结果，也不把两者未经版本区分混成训练真值。
- DecisionStudent 与当前 Laya 教师 checkpoint 分开版本化；独立 reviewer/验收筛选规则、KEEP/DROP/HOLD、离线评估和批准后上线边界保持。模型不能自己挑出“自己一定正确”的训练标签。
- 后续具备托管 Jev 时另行配置适配器与切换政策；不可因本地调用失败偷偷外发数据。
- 私密/secret 数据默认不能送到 DeepSeek 或其他托管 provider。仅用户/受信策略明确标记为公开的数据才能按允许名单外发；学习模型无权修改标签或权限。

旧设计里的“当前在线判断只走 Jev”按本记录修订为“只走当前配置并获准的判断 provider，当前选择 Laya”；不改变单一有动作权判断来源、数据谱系或发布门禁。
