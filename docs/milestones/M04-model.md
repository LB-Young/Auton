# M04：执行模型网关与能力注册

> 状态：已完成本次验收范围，见 [M04 验收](./evidence/M04.md)。按用户最新选择，真实执行模型先接 DeepSeek，本地执行模型另做基线。

## 目标与前置依赖

以统一契约接入本地小模型与强执行模型，为后续真实 Agent 执行提供能力。

前置：M02、M03。M01 必须先完成；其余按依赖验收后进入。

## 模块与工厂

ModelGatewayFactory、ProviderFactory、ModelRegistryFactory。对外 Port、配置、实现选择、依赖注入与生命周期遵守 [工厂规范](./module-factory-contract.md)，调用方不得依赖具体 adapter。

## 开发任务

- [x] 实现请求、流式输出、工具协议、错误与 usage 契约；先接一个真实 provider 和一个 Mock。
- [x] 注册 base/adapter/template/runtime/量化版本、工具与上下文能力、位置和健康状态。
- [x] 当前 DeepSeek Flash/Pro 完成真实协议基线；后续本地约 2B/7B 候选逐一做能力/质量基线，不凭参数量判优。当前不宣称已接入本地执行模型。
- [x] 实现超时、取消、限流与明确的可重试错误；输出中断不能自动重复未知外部副作用。

## 前端交付

模型连接、能力档案、健康与费用视图；主对话顶部保持 Demo 来源，真实 Agent 对话接入 M09。页面遵循 [前端规格](./frontend-design.md)，具备加载、空、失败、不可用与权限不足状态。

## 验收条件

1. 相同 Port 可替换两个实现；真实请求可流式返回并记录模型版本、成本和结束原因。
2. 能力不相容和隐私不允许的候选在调用前被排除。
3. provider 不可用返回真实错误，不回退 Mock；断流与完整答复可区分。

## 必验故障

冷启动、模型不存在、限流、流中断、上下文超限、模板/工具 schema 不相容。针对行为做契约/集成或端到端验证，交付可复现步骤与结果。

不接本地 DecisionStudent；执行模型选择策略在 M05 与 M09 集成。

交付实现、相关检查结果、接口/配置/迁移说明和页面演示；由验收证据更新 [总表](./README.md)，不以 Mock 通过替代真实模块完成。
