# M19：决策 student 通用流程与四层评估门禁

2026-11-19，分支 `claude/project-architecture-review-f9de4i`。按用户要求交付可移植训练流程，不在当前电脑选硬件或执行训练。真实 KEEP 数据准入仍关闭，未生成真实已训练的 student，未更改在线判断来源或采用策略。

## 训练与数据适配

`DecisionTrainingFactory`、`DecisionBackendFactory`、`DecisionDataAdapterFactory`、`ShadowEvaluatorFactory` 与 `DecisionTrainingPort` 位于 `auton/training` 内的独立决策子模块，复用 M18 的受限 worker、作业生命周期和存储机制；数据、目录、namespace、API 与执行训练分开。工厂只组装公共依赖，模型/Agent 不反向导入训练模块。

- 只读 M17 `kind=decision` 且当前来源/KEEP/授权仍有效的 artifact。固定 state、原始 typed question、稳定 option ID 与 selected ID；拒绝未来结果字段、未知选项和不匹配问题。
- 正式作业同样要求独立 train、validation、replay、anchor 来源组，先固定 split 再生成适配数据。携带来源组 metadata 只用于统计，不进入模型文本。
- `encoder_choice` 是本项目通用参考模型：部署方登记的 HF encoder 加 LoRA 和共享选项打分头，使用 attention mask 做池化，对当前候选集合计算概率。选项 ID 只负责对齐输出；模型输入是状态、问题说明和候选描述，训练时重排选项并同步标签。
- 这不是 Laya 原始 head 的微调实现。当前固定 Laya 发行包没有上游文档中的训练模块，不调用不存在的入口。原生 Laya/其他 trainer 需审核固定版本并实现 backend port。
- encoder 与 LLM JSON 读出分开导出：后者输出独立问题/JSON 答案与监督位置，仍要求实际模型模板 token mask 验证；当前可运行的参考训练 backend 是 encoder choice，没有宣称 LLM 导出就等于完成 LLM 训练适配。

部署通过独立 `decision_training` 配置选择审核后的基础模型与 image digest，不绑定开发电脑。encoder 模型 manifest 的 template hash 绑定 `ENCODER_CHOICE_TEMPLATE` 协议；不拿 chat template 冒充 encoder 格式。超出实际 encoder/tokenizer 长度时拒绝，不截掉边界、选项或长中文状态。

训练先测固定 seed 模型，然后训练/复测，分别报告各判断点、中文/其他语言和长状态切片。输出保存 adapter+head、优化器、随机状态、实际设备与依赖版本；候选带 `kind=decision`，保持离线、不可发布。恢复继续校验原始谱系与文件 hash；没有梯度的参数允许没有 Adam 状态，但残缺的已有状态拒绝恢复。

所有训练计划还绑定本模块实现文件的内容 hash。修改数据适配、worker 或门禁实现后，旧计划失效，避免相同配置名偷偷指向不同训练代码。

## 指标与四层证据

参考 worker 输出 accuracy、按稳定语义标签的 macro-F1/混淆矩阵、Brier、NLL、10-bin ECE、coverage 与 answered 子集准确率。全部弃权时 coverage/总体正确率为零，子集准确率为 null，不能靠全弃权获得通过。没有严重错误标注时严重错误数为 null，不把“没标注”变成“零事故”。

按来源组汇总“组内全部正确”的描述性 Wilson 区间，重复同组样本不增加独立组数。该区间不是配对任务收益区间，也不能在反复挑选候选后充当正式显著性检验。指标的标签依据明确为 `qualified_KEEP_teacher_targets_not_independent_gold`。

四层报告只消费已登记候选、其实际结果与公共 Agent/Assess Port 的原始证据，不接收用户 POST 一组自报指标：

| 层 | 当前能检查的证据 | 仍需目标环境补齐 |
| --- | --- | --- |
| 判断 | teacher KEEP 标签下的描述性指标、协议与选项对齐 | 独立金标、多解/score 定义、关键错误与未知域 |
| 持续学习 | seed 对照、replay/anchor、可引用 champion 的谱系 | 真实 approved champion 配对回归、预声明 seed/消融计划 |
| Agent | 配对 run 的实际执行模型/工具/资产/预算/目标/独立验收，以及 candidate 是否真的被采用 | 完整隔离分支执行、足够独立家族、配对统计及安全门禁 |
| 部署 | 实际训练环境与精度记录 | 精确 bundle 的冷/热延迟、峰值内存、并发/OOM、量化与总成本 |

任何完整 Agent 对比都必须引用不同的真实 run/current report，并固定除判断组件外的条件；只有真实采用对应 candidate 的轨迹才可计数。默认生产 runtime 没有启用 student，因此不能用普通 teacher 轨迹填出 student 采用证据。

当前报告保守保持 `HOLD` / `release_eligible=false`，列出缺失项，不把 teacher 一致率或工程测试升级为上线证明。没有真实独立决策金标和完整闭环证据时，这个门禁不会打开。

## 离线预测与影子边界

参考 worker 可保存 validation 集实际预测。文件 hash 随候选不可变登记，读取时重新验证来源、模型 checkpoint 与预测文件；符号链接、篡改、缺失或来源变化均拒绝。

`shadow-replay` 只提供**历史留出预测回放**，包含稳定选项概率、teacher/student 分歧、原始 state 摘要与 `adopted=false`。协议直接标 `historical_validation_not_live_shadow`，`live_distribution_verified=false`，`agent_benefit_verified=false`。它不是实时在线影子实现，不会改变动作，也不能证明 student 改变早期判断后的收益。新鲜盲测、实时影子采集及完整隔离 Agent 执行仍是目标环境的独立验收项。

## API、页面与状态

`/api/v1/decision-training/{status,plans,jobs,bundles,evaluations}`；作业控制使用版本与幂等请求，留出预测通过 `bundles/{id}/shadow-replay` 读取。页面 `?view=decision_training` 与执行训练分开，显示数据/资源/模型谱系、计划阻塞、作业进度、候选、四层缺失项和离线回放；默认后端关闭，没有本机安装、训练或隐式 student 路由。

新增模块与 M18 共用通用生命周期，但独立数据目录、namespace、配置 digest 和候选种类。旧计划遇到实现/配置变化按保守规则失效，没有改写既有数据库表或伪造迁移后的训练证据。

## 验证及未完成的效果验收

专项测试覆盖稳定 ID、选项重排/标签同步、未来字段与非法目标拒绝、全弃权与概率 NaN、重复来源组计数、encoder/LLM 导出分离、候选不可发布、四层缺失时 HOLD、离线预测不采用与文件篡改拒绝；共用 M18 的取消/恢复、OOM、磁盘、来源撤回及重启测试。

最终 `make check` 全部通过：263 项后端测试、217 个文件 mypy strict、33 个 Python 导入边界，以及前端边界、契约漂移、秘密扫描、lint/build。全量浏览器 22 项通过（77.75s），覆盖独立决策训练入口、默认阻塞、禁止启动、刷新与移动端。测试中的模型文件与 worker 都是明确的控制协议替身，产物标 `source=test`，不能作为真实权重、准确率或隔离效果证据。

**尚待目标环境验收**：真实训练/数值恢复、原生 Laya 或其他新 backend、LLM 实际模板训练、新鲜独立 gold、champion 对照、完整隔离 Agent 实验、实时影子、真实量化/资源测试。当前不以通用流程测试替代这些结果，不开放 student 自动接管。后续 M20 发布流程继续独立复核。
