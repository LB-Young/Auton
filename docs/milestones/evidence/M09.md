# M09：受控单 Agent 运行时验收

日期：2026-11-18。M08 已独立验收并推送 `5084ef8`。本里程碑先实现受控单 Agent，不引入多 Agent 调度。

## 工厂与执行闭环

新增 AgentRuntimeFactory、SessionFactory、RunFactory、RunRepositoryFactory 和公开 AgentRuntimePort；bootstrap 显式注入上下文、执行模型、判断、工具、资产与事件 Port。CLI 由 AgentClientFactory 建立本机 HTTP 客户端，调用与任务页相同的应用接口，没有独立业务循环。后端/CLI/脚本/测试使用 Python，浏览器沿用 React/TypeScript。

执行链路：创建任务和稳定主体/项目 session → 排队 → 本地 Laya 判断建议 → M08 上下文装配 → M04 执行模型 → 验证允许工具 → M06 准备/审批/执行/记录 → 回填真实 tool receipt → 继续模型调用或交付 → 宿主独立核对。

执行模型只接受用户显式选择的已注册 ID。Laya 的原始判断、完整 DecisionSource、raw_event_id、route、adopted 状态和输入截止点都保存；本次只调用 decide，不调用 apply，不改变 M05 自动采用门槛，也不切换判断 provider。执行结果保存实际 reported_model、fingerprint、usage 和来源；测试模型仍为 test 标记。

工具名称从固定目录映射为 file_read/file_write/process_run/mcp_sha256；只允许本任务显式列出的工具，参数再由 M06 schema/路径/工作区/策略验证。模型不能提供 principal、根目录、审批凭据或授权范围。资料调研强制只读；process_run 仍只有 M06 固定程序，没有任意 shell/Python 执行。

## 状态、控制与持久性

状态为 queued/running/waiting_approval/blocked/pausing/paused/cancelling/cancelled/succeeded/failed，检查合法转移。创建和控制命令使用稳定 request_id，命令摘要与版本化 checkpoint 原子写入；重复输入幂等，改输入/旧目标修订被拒绝。每个副作用前先保存意图，完成后保存实际结果，不凭模型自述标成功。

暂停/取消在运行时确认。收到停止时不再发新动作，已在途的模型/工具调用先返回或超时；已发生的写入及 receipt 仍记录，然后在安全边界确认。未知写入保持 blocked，显式对账；只有工具账本证明尚未派发，才可解除不确定状态。审批过期回到同一操作审阅，不复用旧凭据。

用户修订先请求安全暂停。在途旧模型结果只记观察事实，不再导出新工具动作；安全点更新目标修订、清理旧待执行调用/审批和模型输入。真实历史结果、用量与已发生副作用保留审计，不能用修订抹去。中断的 model intent 不允许被修订直接丢弃，必须先按同一 ID 恢复/核对；M04 不会自动重发未知请求。

安全 checkpoint 包含目标/修订、完整历史、待执行调用、计划、审批引用、工具 receipt、模型结果、判断来源、context ID、计数和阶段，保存在 M02 EventLog。当前 `state_cutoff` 的单位明确是 **run checkpoint version**，由 `input_cutoff_unit` 标识，不能当全局事件 cursor；M10 将提供独立事件处理游标和投影。

首次读取进程中断的活动任务会转 blocked，等待显式恢复；不自动重放副作用。模型恢复使用原请求 ID 和快照，工具恢复先经过 M06 reconcile，确认成功的结果不重新执行。安全暂停点经同一可信主体重建运行时后可继续。完整投影/进程崩溃恢复管理在 M10；M11 再完成浏览器与 CLI 跨后端重启的持久身份。CLI 发现服务端身份已失效会明确报错，不静默换身份继续旧任务。

单进程租约由本机 flock 保证；同一个运行目录不允许两个执行器同时拥有。多个服务访问同一事件库必须使用同一个 agent.directory，本次没有分布式执行租约。默认最多 2 个活动 run，队列最多 100 个；同项目任务列表最多 100 个 run，单 run checkpoint 少于 65536 个。

## 预算、阻塞与验收

默认单 run：最多 8 次模型调用、8 次工具调用、16000 tokens、10000 microUSD 登记价格估算，输出最多 512 tokens。调用前检查 M08 保守准入和费用预留，M04/M03 再做独立门禁；确认结果后累计实际 usage。未知用量保留于 M04 账本，不伪造已结算数字。总步数、工具上限、重复同参数工具循环、上下文过大、断流、无凭据、来源不可用、非法工具和未知操作都明确阻塞，不换模型重试。

文件交付必须由用户预先提供路径和 SHA256；宿主通过 M06 artifact 重新读取当前文件并比对摘要。报告检查至少指定数量的 `[asset:ID]`，全部引用属于本次保留证据，正文达到最小长度。报告作为持久结果可下载，文件从真实工作区按摘要下载。

`semantic_quality_verified=false` 始终明确：文件摘要验证字节，引用检查验证结构/来源，均不证明泛化语义质量，也不取代 M13 独立评估。当前调研使用已有审核资料，不提供尚未实现的互联网搜索/抓取。资料/任务事件仍保留本机审计副本；逻辑撤回不是物理擦除，报告下载及新执行继续重新验证 context 来源。

## API、CLI 和前端

新增：POST/GET `/api/v1/agent/runs`，GET `/api/v1/agent/runs/{id}`，POST `/api/v1/agent/runs/{id}/commands`，GET `/api/v1/agent/runs/{id}/report`。主体从已有本机身份构造，浏览器不能伪造角色，写命令沿用 Origin/client 门禁。

任务页提供项目/工作区/模型、任务与边界、只读报告/精确文件验收、数据外发声明、真实对话记录、审批卡片、停止/暂停/修订/恢复/对账、计数、来源和下载。状态以服务端为准，刷新后可重选同主体任务，旧响应不覆盖新版本。主对话 Demo 保留明确标记；测试模型 UI 显示“测试替身”。

CLI：`scripts/agent_cli.py init/create/get/list/command`。init 可创建自己的项目和不可变工作区范围，`--editable` 明确允许申请写入，`--notes` 显式导入/晋升所选文本；已有不同资料不会被覆盖。CLI cookie 位于忽略目录、权限 0600，只连接本机 HTTP origin，不打印凭据；浏览器与 CLI 默认隔离。

配置 `[agent]`：directory、max_steps、max_tokens、max_cost_microusd、max_tool_calls、max_active_runs、max_output_tokens。沿用 EventLog，无新增数据库表。测试新增显式 `models.fixture_scenario="agent_acceptance"`，只能与 mock backend/test profile 使用；默认真实配置不会加载合成响应。

## 验收结果

- `make check`：153 个非浏览器测试通过；Ruff、strict mypy、16 项 Python 边界、前端边界、API/生成类型漂移、lint/format 和生产构建通过。
- `AUTON_BROWSER_CHANNEL=chrome make e2e`：11 个流程通过。M09 覆盖真实 Git 项目/审核资料、测试模型的完整运行时、报告下载、等待精确写入审批、批准后写真实文件、SHA256 验收、下载、刷新和手机无横向溢出。显式测试来源不作为真实模型证据。
- 单 Agent 测试覆盖：真实工具与独立验收、模型自称成功但引用伪造失败、循环上限、模型断流、取消/暂停/修订与晚到模型结果、在途写入先记 receipt 后确认停止、未知操作对账、审批过期、未派发证明、预算在调用前阻塞、稳定命令 ID/冲突、旧修订、跨主体/伪造角色、单执行器租约、安全暂停重建、CLI 身份权限/失效及项目初始化。
- `make agent-smoke`：真实本地 Laya + DeepSeek Flash + 固定官方 tokenizer + SQLite 事件 + Git 资产 + 真实 M06 文件工作区，两类任务均 succeeded；结果保存在本机忽略的 `test-results/agent-smoke.json`。
