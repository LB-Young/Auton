# M12：真实任务工作台验收

日期：2026-11-18。M11 已验收并推送 `ca872a6` 后才进入 M12。

## 交付与边界

默认首页接真实 Agent，项目/工作区/执行模型由用户选择，公开外发保持显式授权。任务创建、模型与工具消息、审批、暂停/继续、修订、停止、产物预览/下载和反馈共用 M09–M11 的授权 Port。原 createChatFeature 的 Demo 使用 `?view=chat` 和独立侧栏入口，不能在真实模型失败后接管。

WebAppFactory 组装应用，createProjectsFeature 管理项目公开接口，AgentController 负责查询、选择、请求、事件与竞态，ArtifactViewerFactory 渲染已授权文本。React 页面只使用 feature/controller；transport 不 import 业务实现，feature 不跨读其他 feature 内部 store。API/WS 类型由 Python 导出后生成。

本次工作台面向 M09 已实现的受控任务域：精确文件和已有资料调研。项目作为持续工作范围、每个任务保留独立 run。恢复只续接已暂停任务；终态必须新建 run，原记录保留。没有把新任务伪装成自动携带无限旧消息的自由聊天，也不默认联网搜索、任意代码执行或开放其他文件路径。

## 状态、路由与阅读体验

- 默认真实首页；明暗主题、桌面/390px 导航和原有 Demo 面板继续可用。
- `view/project/run` 查询参数恢复已授权记录；不把提示词、密钥或 Cookie 写到 URL。刷新直接读持久检查点，未授权/不存在项目明确失败，不悄悄显示另一个任务。
- 控制器在启动、项目、选择和查询层分别使用 generation；切换后旧 HTTP/WS 响应不能回写当前任务。精确版本单调采用，重复通知串行合并，断线只读恢复，不重发命令。
- 同一未确认提交重试复用原 request_id；失败保留输入。新任务清空目标内容，编辑草稿仅在本页应用内存中保留，切换模块可找回，重新加载不声称保留未提交敏感输入。
- 输入法 composing / keyCode229 的 Enter 不发送；Enter 发送、Shift+Enter 换行。动作忙碌时阻止再次发命令；显式用户动作才执行工具。
- 消息区有最大阅读高度、键盘滚动与“查看最新消息”；用户向上阅读后事件更新不会强行滚到底部。Markdown 代码可复制，复制失败有反馈。
- 真实报告/文件通过已授权 URL 获取；预览仅文本/Markdown，禁原始 HTML 与危险协议，不解析任意系统路径。大预览拒绝显示而保留授权下载；面板响应式宽度可调整，Escape 关闭并回到触发控件。

## 历史与反馈契约

`GET /api/v1/agent/history?project_id=&after=&limit=&search=` 返回 RunPage。服务端验证项目权限，从该 owner 派生的 project/session scope 遍历原始 EventLog，只把已验证的第 0 版检查点作为新任务入口，再读取其最新状态。按创建顺序、每页默认10/上限20；一次最多扫描1000条，可能空页但 next_cursor 继续推进。搜索目标文本不区分大小写；不匹配任务的后续事件不会重新插入筛选列表。旧整体 list 接口保留兼容，分页已验证超过100条仍可完整读取。

`POST /api/v1/agent/runs/{id}/feedback` 绑定 request_id、goal_revision 和实际 checkpoint version，存入原事件日志；不同输入同ID冲突，同输入重试幂等，跨owner/角色/缺少源检查点拒绝。category区分交付与审批，label_source=human-feedback、verified_quality=false。用户标签、审批偏好不是模型 judge 结论或 gold，不因记录完成就成为训练正样本。

拒绝审批先记录相应来源与理由，再用所展示目标/检查点的 CAS 取消任务。若同时发生修订、审批过期或状态改变，后端拒绝旧动作，不能借前端按钮绕过。反馈已记录与取消确认是两个明确操作；两者不宣称跨模块原子事务。

## 联调发现并修复的执行缺陷

原 M09 修改 Agent 目标后，M03 goal revision 未同步，恢复会被判断层以 stale_revision 阻塞。新增用户专属 synchronize_goal：仅在已验证的用户 resume 中，用已持久化 run 的实际 revision 对齐控制层；runtime 不获准提升版本，旧版本不能倒退，允许用户暂停期间多次修订后统一对齐。对齐在排入 worker 之前完成，重试幂等，既有 reservation/已收费用不清零。

测试包含目标1→2→3连续修订、恢复后重新等待新审批、旧目标审批被409拒绝、runtime自行同步被拒绝。强制未知模型/工具的原有对账门禁继续生效，不用更新权限版本掩盖未决操作。
