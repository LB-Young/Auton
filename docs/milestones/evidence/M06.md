# M06：工具宿主、执行隔离与操作账本验收

日期：2026-11-17。前置 M05 已独立提交并推送为 `9c35a21`；其模型质量门槛仍保持，不因工具交付而打开自动采用。

## 交付

ToolHostFactory、ToolAdapterFactory、SandboxFactory、OperationLedgerFactory 提供统一 schema、发现/准备/审批/执行/凭据/对账/产物 Port，bootstrap 编排生命周期。真实实现包括文件读写、固定 Python 子进程和 MCP stdio，没有用 Mock 替代工具验收。

人类控制面创建独立工作区并固定只读权限，工作区绑定目标和修订；运行时无权创建/放宽作用域。HTTP 不接受调用者自选 principal、目标或根目录，owner cookie 不进入公开工作区响应。当前根目录为忽略的 `.auton_local/tools`，没有授权工具修改本仓库或用户其他目录。

### 文件与进程边界

- POSIX 目录描述符相对访问，路径逐段 O_NOFOLLOW；拒绝绝对路径、`..`、隐藏路径、Windows 路径、符号链接、硬链接、FIFO 和非普通文件。只支持有限大小的 UTF-8 文本。
- 只读不创建缺失子目录、不写入、不启动进程。可写操作先生成差异，再批准绑定确切输入/操作/目标/策略版本和期限；执行前再次授权。
- 写入先核对预期 SHA256，新建要求原文件不存在。工作区锁文件在创建作用域时建立，写时只打开已有文件并用 flock 串行化协作进程；临时文件 fsync、原子替换、目录 fsync。并发测试曾发现执行阶段创建锁文件的竞争，修正后针对该场景重复八次通过。
- 首批进程只允许 Python 版本与 AST 语法检查，不执行输入代码。真实子进程使用固定入口、限制 CPU/文件大小/文件描述符，不继承 API key。异常语法返回真实非零退出码，超时终止本次子进程。
- **这是协作进程的受控目录与固定程序白名单，不是 OS 安全沙箱**，也不承诺防御同一 OS 用户的恶意目录重命名/锁破坏。任意 shell/Python 执行须等后续 OS 隔离适配，不用当前子进程冒充此能力。

### 操作与产物

- 逻辑 operation_id 对同一主体稳定，attempt 固定为首次派发。相同 ID 不同输入冲突；已完成返回原凭据，started/unknown 先对账，不盲重放。
- 授权 begin 与 started 意图持久化后才派发。实际结果先保存 received，再结算工具预算和发布 completed；完成事件丢失可恢复而不重复副作用。
- 写成功但确认丢失返回 unknown。对账只读取实际摘要；匹配则标注“目标状态已观察到”，明确它不是找回原执行确认。摘要不同/不存在继续 unknown，不凭推测重写。
- 工具失败有独立 outcome/code/exit_code；未知、失败和成功不能被模型文字覆盖。每次已派发调用计入工具预算，取消不把未知副作用当未执行退款。
- 凭据保存工具/输入摘要/目标/工作区/attempt/证据。文件 artifact 保存相对路径、字节数、SHA256；下载重新验证当前摘要，文件后来变化则拒绝旧凭据下载。响应固定 attachment/text/plain/nosniff。
- 工具输出标 `untrusted=true`，页面用文本显示而不执行 HTML。凭据中的 credential-like 内容脱敏；原始本地文件仍受作用域控制，明确下载返回其经校验的真实字节。

### MCP

固定本地 Python stdio SHA256 服务真实执行 initialize → initialized → tools/list → tools/call，验证版本、工具名、schema 和结构化摘要；注解不承担授权。它证明首个 MCP 适配器可运行，不宣称通用外部 MCP/远程 HTTP/任意插件已实现。

## 接口、配置与限制

`/api/v1/tools`、`/tools/workspaces`、`/tools/operations`，以及 operation 的 approve/execute/reconcile/receipt/artifact 接口。前端“工具”页展示工作区权限、工具 schema 对应表单、差异/固定程序预览、逐次批准、真实凭据和未知对账。

`ApplicationConfig.tools` 控制根目录、只读总限制、大小、超时与固定 MCP 是否启用。事件复用 M02 schema，无数据库 schema 迁移；不新增外部依赖。

当前仍是单机原型。浏览器 owner 授权集合跟随后端进程，重启后新身份不能直接访问旧作用域；持久身份与跨重启工作台恢复接 M11。工具任务的项目目录映射与任意程序隔离尚未开放；真实 Agent 接 M09，当前工具页由用户直接操作。该限制没有用虚构账号、任务或沙箱掩盖。
