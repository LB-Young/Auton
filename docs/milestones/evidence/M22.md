# M22：新对话自动学习数据链路验收

2026-11-22，分支 `feat/conversation-workspace`。使用方式、接口和边界见 [自动学习数据指南](../../conversation-learning.md)。

实现独立 `learning` 模块及 Factory/Port，接入会话创建/读取与应用生命周期。后台发现每轮任务，保存固定版本、处理阶段、调用预留和独立证据 ID；授权后自动复核、调用原有 datasets 准入并导出 canonical JSONL。默认只登记采集，不调用付费模型、不训练、不发布。

新增多轮历史检查点证明、response 人工校准题型、独立回复监督转换及 worker 对最终文本的精确 token mask 支持。固定会话划分并防止重复正样本；撤回前序轮次会使依赖历史的样本失效。训练读取支持有界批量产物与显式跨项目授权，逐一复验原始产物；两类监督保留各自格式和原始谱系。

验收：

- Python 静态检查、格式检查、mypy 通过。
- 全量后端测试 **335 passed**（35 browser deselected）。
- 隔离服务和端口的 Chrome 回归 **35 passed**。
- 前端 ESLint/Prettier、TypeScript 与生产构建通过；旧任务页面补齐空 `prior_runs` 字段。
- API/TypeScript 契约一致，用户参数文档与源码一致；**44** 条 Python 导入约束及前端模块边界通过。
- 新增 13 项测试覆盖后台无手动 tick 发现、无授权零调用、重启/幂等/身份隔离、额度、未知调度不重发、多轮来源和分组、影子决策 HOLD、测试来源隔离、合格端口后的导出/失效、历史撤回传播、批量训练和目标 mask。

质量限制：所有新测试使用合成轨迹；合格分支的单元测试模拟独立资格，不是生产标签、真实校准或训练效果证据。生产 response 数据仍须真实独立校准、有效授权和完整来源。代码改动仅凭文字复核不会转成正样本；需要独立执行/交付验收。当前未实际采用的 Laya 建议只记录 HOLD。没有自动启动本机或其他环境的模型训练，也没有激活模型。
