# M11：本机服务协议验收

日期：2026-11-18。M10 测试、提交并推送 `c951005` 后进入 M11。

## 范围与工厂

ServerFactory 完成 API 组装；IdentityFactory、CommandHandlerFactory、EventStreamFactory、UploadFactory 分别暴露身份、命令、运行事件及文本导入 Port。bootstrap 注入应用级实例并按依赖顺序管理生命周期；handler 不导入 agent、资产、轨迹或模型实现。前端通过 transport/feature 工厂使用同一 HTTP/WS 契约，Python 负责后端、测试、契约导出和辅助工具。

本次交付本机共享服务协议，不启用公网部署、跨设备账号或后台多 worker。M09 真实任务仍在任务页；主聊天 Demo 到 M12 再调整。独立语义评估、训练与发布仍未实现。

## 身份、权限与迁移

默认 `.auton_local/server/identity.sqlite3`，SQLite WAL/FULL、0600、进程独占租约。当前有效 bearer Cookie 仅保存 SHA256，内部 owner 使用独立随机标识；JSON/WS 不返回 Cookie。HttpOnly/SameSite=Strict，默认 30 天固定到期，bootstrap Max-Age 不得超过服务端有效期。有效 Cookie 经服务重启仍映射原 owner；失效 Cookie 返回 401，不静默切换 namespace。显式新建身份不会转移数据。

升级前 Cookie 同时是旧 owner。设置页提供显式迁移：须持有原 Cookie，输入其拥有的项目 ID，服务端通过资产 Port 只读验证实际归属，再在一个 SQLite 事务中保存新 Cookie 的散列与旧 Cookie 撤销标记。原 owner 保持不变，旧 Cookie 撤销后无法重复迁移。旧 owner 字符串会作为已撤销凭据的历史 namespace 保留；当前有效新 Cookie 不写入数据库。丢失旧 Cookie、过期的新身份和跨设备恢复没有自动认领入口，原数据不删除。

写 API 校验身份、X-Auton-Client 与来源白名单；浏览器 WebSocket 必须具有允许的 Origin。跨 owner/project/run/文件不能靠 URL 或请求体伪造 principal。HTTP ASGI 层只接受回环客户端，拒绝超大 Content-Length 与 chunked body（2 MiB）；响应默认 no-store/nosniff。身份/上传记录上限各 1000，创建新记录时清理过期超过 7 天的记录；旧身份迁移的撤销标记保留。未知 SQLite schema 拒绝启动。

## 命令确认与请求生命周期

创建/控制/恢复任务使用稳定 request_id；目标修订与检查点版本分别由 expected_goal_revision / expected_version 做并发校验。HTTP 响应确认命令已记录，不能当成任务已完成。CommandHandler 对在途命令做最多 64 项的并发去重与参数摘要冲突校验；实际持久幂等来自 agent/experience 原有日志，不以进程内 map 替代。

HTTP waiter 取消不会取消命令任务，关服务先等待命令和上传收尾，再让 agent 在安全边界暂停；不会把关闭进程解释为用户主动停止。仍在途的模型/工具结果保留观察与操作账本，迟到结果不能越过暂停采用。强制崩溃依然按 M10 明确阻塞/恢复协议处理，不盲重放副作用。测试不会把连接断开等同于后台进程重启。

前端同一未确认请求的重试复用原 request_id，不在网络错误后立即换 ID；重新连接本身只读，不自动重发命令。内存 pending map 上限 64；页面刷新后必须先查任务列表/快照再操作，不宣称跨页面持久化未确认输入。CLI 使用相同服务端命令 API 和原有私有 Cookie 文件。

## 事件流协议

- `GET /api/v1/agent/runs/{id}/snapshot` 返回完整公开 run、精确 checkpoint_event_id、持久 cursor 和匹配的临时 progress。
- `WS /api/v1/agent/runs/{id}/events?after=cursor` 为只读通道。每次连接先发送当前 snapshot 锚点通知，然后按原始 EventLog 的 scope/cursor 分页重放 checkpoint 通知；并非把所有原始事件 payload 发送给浏览器。客户端据通知重新拉取授权快照。
- RunFrame schema_version=1；kind 为 snapshot/checkpoint/delta/heartbeat/reset_required。持久通知 cursor 指向已提交检查点；delta/heartbeat 不产生持久游标。after 必须是该 run 的有效 checkpoint，越界或非检查点游标要求 reset，并以当前快照重新对齐。
- 先收到当前锚点后可能收到较早的补发 checkpoint。客户端 cursor 取最大值，run 只接受不低于当前 version 的快照；合并重复通知，串行拉取，避免旧响应回退状态。生成内容按 request_id/version/goal_revision/sequence 显示，暂停、修订或最终结果后停止展示旧临时内容。
- 临时 progress 为最近累积文本，最多 16000 字符；断线可补取当前进度，进程重启不恢复这些 delta。模型最终确认结果才由既有网关与 run checkpoint 持久保存，不承诺逐 token 历史。
- 每个身份最多 4 个 run socket；每页默认 32 条，发送默认超时 5 秒；慢消费者被关闭且释放槽位，不取消后台任务。每次发送和等待周期再次检查身份有效性。读通道不会执行工具或审批。

模型实际运行已改用 M04 stream，运行修订号 `single-agent-v2`；历史 v1 检查点可读取，显式 resume 后更新为 v2。Experience 接受 v1/v2，未知版本仍拒绝恢复。执行网关默认修订为 `deepseek-http-sse-v2`。敏感值跨 chunk 也在发布前脱敏，最终结果与工具参数再次脱敏；涉及敏感输出的工具调用阻塞，防止改变后的参数被静默执行。

## 文本上传与 artifact

`POST /api/v1/uploads` 声明 request_id、project_id、filename、size_bytes、SHA256，验证项目归属并固定候选区 CAS；返回意图和到期时间。`POST /api/v1/uploads/{id}/content` 接收 `application/octet-stream` 原始字节，按流累计限额，核对实际长度/SHA256/UTF-8/字符数。默认上限 128 KiB / 32000 字符，10 分钟到期；无任意本机路径或二进制解析。

结果只成为带 upload ID/摘要来源的 untrusted 用户导入候选，不自动晋升正式资产。意图/receipt 存 SQLite 元数据，原文进入既有 Git 资产仓库，不建立无授权 blob 路径。同请求同输入幂等，不同输入冲突；上传 receipt 丢失后先核对已提交的对应资产，不重复生成 Git 变更。并发候选修改导致 CAS 冲突时明确失败，不能悄悄覆盖。

已有报告、文件 artifact 下载继续通过 agent/tool 的公开 Port 校验归属、来源撤回和实际摘要；HTTP 响应的 no-store 不替代这些验证。未完成的上传不生成临时文件；过期意图拒绝写入。前端资产页完成上传、候选展示、错误处理和显式晋升。
