# M07：版本资产、项目资料与记忆治理验收

日期：2026-11-17。M06 已独立测试并推送 `ee0a8df`。

## 交付与存储

GenomeFactory、AssetRepositoryFactory、MemoryPolicyFactory、ResolverFactory，显式 Port、依赖与生命周期。默认 `.auton_local/genome`，每个主体/项目独立 bare Git 仓库，根和主体目录权限 0700；不使用本项目 Git 分支保存用户资料，也不把本地资产推送外网。

资产 schema 包括 Skill/Prompt/role/knowledge/document/memory、稳定 ID、名称、来源类型、人工来源引用、内容、父资产和到期时间。来源引用是声明，不代表已自动验证。项目注册包含范围 ID、标题和说明，不允许输入任意磁盘根目录。所有资产文本保留 untrusted 标记，不授予工具或角色权限。

正式分支 main 与候选分支 learning 分开。资产 JSON、schema 版本及动作/角色/时间审计元数据进入 Git 内容对象，比较旧 commit ID 后更新 ref。并发旧版本发布被拒绝，不静默合并；人工回退把旧内容写成新提交，不改写历史。当前单项目最多 1000 条记录、catalog 最多 8 MiB，单资产 32000 字符，历史接口最多最近 100 个正式提交，来源图有保守上限。

## 治理与权限

- Reader Port、Proposal Port、Publish Port 分离。运行时读取正式资产；evolution 只能提出候选，不能伪称用户显式记忆，也不能晋升正式分支。只有 user 控制面可创建项目/晋升/撤回/回退。
- M03 新增 asset.read/asset.publish 固定动作；角色边界与策略预检先于资产操作，固定策略拒绝时不执行。默认配置版本因此改变，旧授权不应继续使用。
- 用户显式记忆、推断记忆和外部导入保留原始来源标签，晋升不把推断伪装成用户声明。外部 Skill 只作为数据保存，不能加载插件、执行代码或修改固定策略。
- 晋升校验候选分支和正式分支版本、名称冲突、父资产范围、依赖循环与过期时间；坏 schema 由严格契约拒绝。
- 撤回会把当前内容替换为 tombstone，递归撤回正式派生资产，隐藏不可用候选，后续 Resolver 不再选中。已撤回 ID 不能被晋升或回退偷偷复活。
- 当前记录/历史记录的过期限制及来源限制都作用于快照读取；旧快照不能绕过新的撤回或更短的保留期。界面显示不可用记录原因，正文不再返回。

## 使用快照

Resolver 按稳定 ID 排序，只选当前主体/项目内可用正式资产；输出包含正式 Git commit、项目说明、具体内容、来源和父引用，内容摘要形成稳定 snapshot ID。AssetUsed 事件保存引用与具体快照，同一有效快照可重复取回原内容。

已有快照再次读取仍检查当前撤回、过期和来源状态。可复现不意味着无视撤回；允许时返回原内容，权限/保留条件不允许时明确拒绝。跨主体或跨项目使用 snapshot ID 不会得到其他项目资料。

## API 与前端

项目列表/创建、资产列表、候选写入、人工晋升、撤回、历史、差异、回退、快照创建/读取 API。主体从已有本机归属构造，不接受浏览器伪造 principal。资产页包含项目说明、来源与到期表单、当前/候选内容对照、待晋升区、正式资产、历史差异/回退及快照，具备加载、空、失败、过期/撤回提示。

项目工具目录映射、自动导入附件/网页、向量索引和自动记忆抽取不在本次范围；M07 先提供人工管理与固定治理，后续 M08/M15 再扩展检索/优化。主对话仍为 Demo，不冒充已使用资产的真实 Agent。

## 明确限制

逻辑撤回会阻断服务端继续读取，但 Git 历史和已有事件保留审计内容，已送到客户端的数据也不能被收回；这不是磁盘物理擦除。需要物理清除时应单独实现受控保留/重写/索引清理方案，不能声称当前已实现。

Git 与 EventLog 没有分布式事务。Git commit 已完成但事件确认失败时，调用方应重读当前版本核对；仓库 commit 中仍有动作审计元数据，不能自动重复发布。外部快照消费者应通过受控读取接口重新验证，不绕过接口直接使用旧数据库内容。

浏览器身份仍受当前后端进程的 owner 集合限制，持久身份与跨重启完整工作台恢复接 M11。当前为单机可信模块边界，不是恶意同用户 OS 进程隔离。
