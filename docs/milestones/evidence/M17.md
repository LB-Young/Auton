# M17：数据加工、快照与谱系

2026-11-19，分支 `claude/project-architecture-review-f9de4i`。交付可追溯、分离、受限的数据加工与导出工程；不启动训练、不发布模型。

## 实现与边界

`DatasetPipelineFactory` 组装来源读取、三类 curator、`GroupPolicyFactory`、`LineageStoreFactory` 与 `ExporterFactory`，通过 `DatasetPort` 使用。数据模块没有模型生成、工具执行或发布权限。Evolution 仅通过窄 Port 提供原始进化请求 ID；包括 baseline 在内的全部分支都被排除。

- **Executor**：核对拥有者、原始 checkpoint、原始模型 started/completed journal、请求 digest、实际模型/指纹、资产版本、真实工具 receipt 与独立验收。首期只收经文件 SHA256 验证的 `file_write` 动作，不把未经独立语义评估的解释文字当答案。保留完整工具调用/响应；只有选定 assistant 动作的位置声明监督，用户、system、工具响应不带 loss。具体 token mask 必须由 M18 对真实 tokenizer/template 验证。
- **Router**：两个实际成功运行的受控比较，验证决策前候选目录 checkpoint、相同原始输入/工具/预算/资产/任务和独立检查；只比较新文件的已知单次写入，按实际观测费用/用量选标签。没有反事实运行、目录缺失或平局时不造标签。旧轨迹不会回填“当时候选目录”。
- **Decision**：只消费 M16 当前合格 KEEP，原始状态与原始判断作监督，未来结果只筛选。Decision teacher 权利范围独立核对；目前真实 KEEP 为零，因此真实 Decision 训练仍关闭。

三类授权分别记录确切 run、用途、模型声明版本、模型条款和外部资产内容 hash。授权默认关闭、secret 排除、local-only 需要显式授权；未知 teacher 条款拒绝。授权记录是用户范围声明，不声称程序能自动验证法律权利。[DeepSeek API 训练使用条款核对笔记](../../references/deepseek-open-platform-training-use.md)只覆盖此次自有公开合成来源。

先以家族/原始来源/实际 DAG/独立验收家族与组、规范化原始输入指纹建立连通分组，再固化 train/validation 划分。长文本使用版本明确的字符 5-gram Jaccard 0.92 启发式近重复筛选；不宣称能识别任意语义改写。冲突组拒绝派生；后来合并的组会使旧统计/快照失效。test/meta、reviewer meta 与优化实验禁止进入训练。

## 存储与接口

私有 SQLite WAL/FULL、单进程 lease、不可变版本、CAS 和幂等 receipt；原 Evolution/DecisionReview 私有存储抽为 Kernel 的通用版本文档存储，路径/表结构保持兼容。主事件日志只记谱系摘要，不复制私有训练内容。

`/api/v1/datasets` 提供 status、grants、snapshots、withdrawals、exports 与 artifact 下载。快照固定来源、授权和内容 digest；导出按 split/purpose 分开、限字节数、0600、无符号链接、hash 校验。幂等导出可补回缺失文件，冲突内容拒绝覆盖。导出提交及读取前后均重新检查来源。撤回永久阻止后续导出/下载，返回受影响快照；确认丢失后的重试不重复撤权。原始来源、旧 KEEP、授权或配置变化也会阻塞后续使用。

不承诺删除已经下载的文件，也不销毁审计。M18 worker 必须复核来源并跟随撤回停止使用，不能把任意本地 JSONL 当长期有效授权。

`?view=datasets` 提供授权、三类构建命令、质量/拒绝原因、分组/来源、消息监督范围、导出与撤回；授权默认 false，有加载、空、错误、权限失败及移动端状态。
