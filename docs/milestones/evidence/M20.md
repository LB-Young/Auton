## 实际运行链路

Agent 创建时冻结实际 executor ID、模型 manifest 和资产 snapshot；Context/ModelGateway 在 tokenize、generate 和后续工具执行前检查获准来源。模型 activation 真实切换私有项目 profile；`project_default` 为用户显式选择，稳定 goal hash 控制比例，evaluation 授权没有默认模型切换权。资产小比例使用固定 snapshot overlay，100% 使用 Git CAS 写入，回滚使用原始兼容父版本与回执。

独立新鲜 release 窗口、完整 protected test、质量与用量以及实际部署身份须同时通过。执行模型还需同条件完整成对基线及按连通分量统计的模型延迟改进。不得把操作性通过、历史 KEEP、一致率、fixture、字节级文件验收或配置为“local”当作生产质量证据。

生产上暂停停止新分配，回滚撤销执行权并取消实际受影响任务；未知工具副作用保留待对账。资产回滚不覆盖后续人工修改。remote fallback 对 local-only 仍拒绝外发。incident 按实际工件身份封禁，不能改作业名重新上线。
