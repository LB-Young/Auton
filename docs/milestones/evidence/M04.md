# M04：执行模型网关验收

日期：2026-11-17。前置 M03 已测试并推送 `8ba8718`。

## 交付

ModelGatewayFactory、ProviderFactory、ModelRegistryFactory 提供显式 Port、配置与生命周期，启动不调用远端。实现真实 DeepSeek 与仅 test profile 可用的 Mock；不可用、缺凭据、限流与断流均不会回退 Mock。

统一请求覆盖文本、JSON、工具消息与工具 schema；流式增量、完整结果、用量、结束原因和错误分开。模型目录保留声明版本/上下文、操作限额、能力来源、健康状态与价格修订。未公开的 base/adapter/template/量化版本为空，服务别名明确不视为不可变版本。

模型调用先检查能力/隐私/输入，再持久授权与预算预留、begin、派发。按 owner+request_id 去重，同 ID 不同输入拒绝；完成结果持久化后结算，received 阶段可恢复结算，不重新调用 provider。取消/断流的未知执行保留待对账额度；已知拒绝结算零消费，真实返回 usage 则按实际 token 结算峰值价格估算。没有自动重试或自动备用模型。

`GET /api/v1/models`、`POST /api/v1/models/{id}/probe` 复用本机来源与归属校验。检测只发送固定公开短句，主体由服务端构造。模型页面展示来源、声明版本、能力、额度、返回版本和 token 用量，具备加载、空、错误、缺凭据与检测中状态。主对话仍为 Demo，真实 Agent 接 M09。

## 验证

- `make check`：70 个非浏览器测试通过，Ruff/mypy strict、6 项 Python 边界、前端边界、契约漂移、ESLint/Prettier、生产构建通过。
- `AUTON_BROWSER_CHANNEL=chrome make e2e`：6 个浏览器流程通过，包含模型目录/检测/手机不溢出与旧流程回归。隔离临时端口和数据库，测试显式 Mock，不调用真实模型。
- 故障覆盖缺凭据、401/402/404/429/500、上下文超限、私密外发、输入凭据拦截、工具 schema、增量参数、usage 两种位置、缺 DONE/usage、无效 JSON、取消、并发同请求、结果持久后结算失败恢复。
- `scripts/model_smoke.py` 实际调用 Flash/Pro，各完成文本、JSON、必选工具三种短测试。六次均真实远端返回，未截断，合计 845 微美元（$0.000845）保守估算。记录见 [真实协议结果](./M04-assets/deepseek-smoke.json)。这不是 Agent 质量基准或最终账单。
- 本机密钥来自忽略的 `.env`；真实请求脚本不打印密钥，提交前额外扫描暂存区。

## 配置与限制

默认 demo 注册 DeepSeek，允许固定 public 请求到该 provider；未配置 key 时模型页显示缺凭据，Demo 仍可运行。测试 profile 必须明确 models.backend=mock；其他 profile 禁止 Mock。环境变量优先于 `.env`。模型事件使用 M02 现有日志，无数据库 schema 迁移。

按用户最新选择，当前执行模型先用 DeepSeek；本地 2B/7B 执行模型待单独质量基线，不冒称已接入。M05 才下载并接入 Laya 主判断模型；Laya 不充当执行模型或 Jev 权重。当前仍为单机可信 Port，尚无完整 Agent、每日全局预算、分布式调度或公网认证。
