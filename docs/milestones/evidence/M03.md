# M03：固定策略、权限与配置验收

日期：2026-11-17。前置 M02 已独立测试并推送为 `789cf0e`；本里程碑不混入模型接入实现。

## 交付与边界

ConstitutionFactory 组装只读配置、确定性 PolicyEvaluator、持久控制日志和角色受限 Port。公开字段包含策略版本、外发 provider 名单、公开数据要求、自主上限、需批准动作与单目标预算；没有密钥值。

策略预检返回 allow/deny/approval_required 和 reason codes。预检不是可执行授权；执行者必须使用绑定操作 ID、输入摘要、主体、目标修订、策略版本与有效期的预算保留，再在派发前 begin 重新检查。模型/训练/进化角色不能修改 Constitution、checker、holdout 或读取密钥。

设置页展示限制并提供两种真实后端预检：私密数据外发被拒绝，工具写入要求批准。它们不调用模型或执行工具。真实动作审批卡在 M06/M20 接入。

## 持久授权与预算

- register_goal/revise/cancel、审批、reserve/begin/settle/release 都使用 M02 事件事务持久化，成功确认后才更新内存控制状态。
- 确定性控制流序号和唯一事件 ID 提供比较并写保护；并发服务读到旧状态不能同时占用相同剩余预算，冲突会刷新并拒绝该次授权。
- 用户 API 修订生成新版本并可重启恢复；初始配置指纹不变时保留用户修订，明确修改配置文件才重新加载该配置。旧授权失效，既有消费不归零。
- 预算单位为整数 token、微美元、工具调用数；这是单 goal 上限，不宣称已实现每日全局额度。
- reserve 幂等，派发前检查取消、版本、主体、审批有效期与剩余额度；相同审批不能被不同 operation_id 套用。
- 未派发保留可释放；started/unknown 需按实际结果结算，取消不自动退款。重启把未决派发标为 unknown，不能再次派发。
- 实际消费超过估算仍记账，阻止后续越额授权，不为“看起来合规”丢弃账单；外部服务最终收费不由本模块保证。

## 配置、API 与密钥

`ApplicationConfig.constitution` 严格校验；未配置远程白名单时默认禁止外发，local-only/secret 不可远程。数据标签必须来自受信任务/用户边界，不能由模型自行降级为 public。

`GET /api/v1/policy`、`POST /api/v1/policy/preview`、`POST /api/v1/policy/revisions` 复用来源、归属和命令头检查。预检 body 的主体会被服务端覆盖为当前 runtime 主体，修订主体只由本机用户控制面生成。配置修订要求当前版本，迟到请求拒绝。

SecretStoreFactory 只通过环境变量名读取环境或忽略的 `.env`，不修改全局环境，不序列化密钥；LoggerFactory 使用独立脱敏 formatter。HTTP 校验错误不回显输入，避免把误填密钥送回界面。提交检查扫描暂存区是否复制了当前本机配置的凭据，输出不含值。

当前仍是单机个人控制面，不等于完整账号系统或 OS 沙箱。角色是由可信调用方提供的上下文，学习/训练 worker 只能获得受限 Port；外部代码执行隔离由 M06/M18 继续实现。
