# DeepSeek 模型与价格：接入基线笔记

- 原链接：[官方模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)
- 查阅：2026-11-17；本文为理解笔记。

目前注册 Flash 与 Pro 的服务别名，分别声明 V4.1-Flash-1017 与 V4-Pro-0813。别名不代表不可变权重：保存声明版本、实际返回模型及 fingerprint，缺失的 adapter、量化、模板信息标为空，不能猜测。

供应商声明的上下文是能力上限；Auton 初期另设 8192 上下文和 2048 输出的保守操作限额。协议基线只证明少量样例能交换文本、JSON、工具参数，不证明复杂任务质量。

按峰值、缓存未命中价格估算费用，用整数微美元记录；预算预留偏保守，收到真实 token usage 后结算。缓存和非峰值优惠会使估算高于实际账单，价格也可能变动，所以估算不能冒充最终收费。后续接本地执行模型时应单独建立能力和任务质量基线。
