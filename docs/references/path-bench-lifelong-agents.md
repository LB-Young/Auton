## 核心观点

长期 Agent 的能力取决于经验积累的路径；学到新经验可能干扰已有能力。

## 机制与证据

- 构造包含有益和干扰历史的任务序列，反复运行探测任务。
- 测量平均表现、前向迁移、后向迁移与遗忘。
- 覆盖代码生成与多轮工具使用；作者提出 Selective Experience Use，选择性使用历史以减少干扰。
