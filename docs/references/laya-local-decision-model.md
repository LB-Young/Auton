# Laya：本地类型化决策模型与微调入口

- 原文：[Laya 官方仓库](https://github.com/NandhaKishorM/laya)
- 来源：维护者代码与 README；查阅：2026-11-16。
- 本文为中文理解笔记，非原文转载。

## 来源要点

仓库提供类型化决策模型，支持选择、评分及是非判断，代码标注 Apache-2.0。训练模块公开 `TrainConfig` 与 `finetune` 入口；不是只有托管推理 API。选项布局等训练配置与 checkpoint 的适配有关。

## 我的理解与 Auton 设计推论

这是本地 DecisionStudent 的优先实验候选：将决策前状态、问题与选项作为输入，以独立复核 KEEP 的 Jev 答案作为监督。它不必生成整段 Agent 回复，训练目标与执行模型 SFT 分离。

适配层应保留 canonical DecisionDataset，另导出该版本训练器接受的字段；不能假设我们的 JSONL 可以直接喂给仓库。先用极小合成集跑通导出、训练、保存和重新加载，再使用真实获准样本。

## 局限与验证

代码开源不表示每个权重或数据自动具有相同许可。不能把特定布局实验的性质推广到所有已发布 checkpoint。应固定代码、权重、tokenizer 和选项布局，验证中文、选项顺序、未知答案、量化影响与恢复能力。无论结果如何，实验都在线下进行，不能接管线上 Jev。
