## 核心观点

项目提供强弱模型路由与评测框架，通过阈值调节成本和质量，并提示按接近真实流量的数据校准，也提供本地模型接入方向。

## 我的理解

要判断的是更强模型的增量价值，而非永远固定的“任务难度”。升级本地模型、改变工具和任务分布后，原路由阈值的证据会变弱。网上某组模型对的阈值不能直接复制到本地 2B/7B。

## 对 Auton 的启示

- 以规则路由、全部强模型和全部本地执行作为基线，Jev 是一个可比较的判断候选。
- 收集同一初始状态上的不同候选表现；线上未选中的模型结果记 unknown，不能凭路由选择生成真值。
- 测难任务误下放、成功覆盖、失败升级后的总成本及路由本身开销。
- 每个模型 bundle 版本绑定经过验证的路由配置，发布后支持一起回滚。

## 局限与验证

对话偏好路由不等于 Agent 业务成功路由；工具、上下文和隐私要求需要额外硬过滤。首期可使用项目思想，不必引入其所有依赖；在同等预算的隔离任务上比较后再决定。
