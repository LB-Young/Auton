## 来源要点

React 通过组件组合界面，支持条件与列表渲染、事件处理和状态共享。组件可以覆盖一个控件，也可以覆盖页面中的较大区域。

## 我的理解与 Auton 推论

Auton 可将对话、任务卡和产物面板拆为组件，将 API/事件订阅与业务控制放到 feature controller。用户要求的工厂模式落在 feature 与可替换适配器创建处，不必给每个函数组件创建类工厂。

应用组装入口为 feature 注入 transport、导航和能力接口；页面不直接获取 secret 或调用模型 SDK。组件状态与服务端任务状态分离，断线后由服务端快照恢复。
