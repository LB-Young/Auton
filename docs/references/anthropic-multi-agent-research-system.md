## 核心观点

研究型多 Agent 擅长分散探索大量资料，但容易重复工作、过度搜索和错误选择工具；委派必须说明范围、输出和信息来源。

## 关键机制与做法

- 主 Agent 组织研究，子 Agent 在独立上下文探索并返回结果。
- 按任务复杂度分配投入，评估事实、引用与工具效率。

## 我的理解

我的理解是并行的价值来自可分解的探索，不来自复制相同搜索。信息量增大后，聚合与证据核查也会成为瓶颈。

## 对 Auton 的启示

- 子任务标明覆盖范围、非目标、证据要求和停止条件。
- 聚合保留矛盾与未确定项；按同等预算比较单 Agent 和团队。

## 局限与适用前提

研究任务对并行友好，不意味着紧密耦合的编码写入同样受益；内部成本比例也不可直接复用。

## 建议验证（尚未执行）

加入重叠子任务和不存在的资料目标，检查重复工作控制与有界停止。
