## 核心观点

Skill 是否有效，需要在同一任务条件下对比加载和不加载 Skill 的结果。

## 机制与证据

- 当前版本包含 87 个任务、8 个领域，配套人工整理的 Skill 和确定性验证器。
- 在 18 种模型与 Harness 配置中做有无 Skill 的配对评测。
- 作者发现聚焦的小型 Skill 组合优于庞大、穷尽式组合。

## 对 Auton 的启示（待验证）

- §6.5、§7.6：为 Skill 保留无 Skill 对照，并区分内容有效、触发正确和组合有效。
- §5.2：记录加载 token 与模块数，验证渐进披露的实际收益。
- §7.4：SkillMiner 生成后必须经过独立任务验证，不能用数量增长代表能力增长。

## 局限

这里的主要证据来自人工整理的 Skill；不能直接推出自动生成的 Skill 同样有效。不同论文版本的任务规模可能不同。
