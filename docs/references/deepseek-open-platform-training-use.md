# DeepSeek API 输出的训练用途：条款核对笔记

- 原链接：[DeepSeek Open Platform Terms of Service](https://cdn.deepseek.com/policies/en-US/deepseek-open-platform-terms-of-service.html)
- 核对日期：2026-11-19。页面标注发布于 2026-04-22、生效于 2026-04-29。
- 这是我的理解笔记，不是条款原文副本。

API 专用协议的 4.2 节明确把训练其他模型、模型蒸馏列入输入/输出的可用用途，但以遵守适用法律和条款为条件。4.1 节仍要求调用者拥有输入所需的权利、许可和权限。

因此，Auton 不能只看“调用成功”就把任何日志变成训练数据。应记录教师版本、原输入来源、具体用途、授权依据和核对的条款链接；第三方材料、个人信息以及其他来源的模型权重还要分别处理。

当前原生验收只选择项目自行构造的公开文件写入任务，并把明确的文件校验和来源谱系保留下来；这个范围不延伸到其他人的私密历史，也不代表训练后的模型质量已达标。
