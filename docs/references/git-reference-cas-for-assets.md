# Git 引用更新：资产并发控制笔记

- 原链接：[Git update-ref 文档](https://git-scm.com/docs/git-update-ref)
- 查阅：2026-11-17；本文为理解笔记。

更新引用时附带旧对象 ID，可以要求当前引用仍是调用者看过的版本；零 ID 用于要求引用原先不存在。这样客户端不能用过期版本悄悄覆盖另一位写入者的更新。

Auton 为每个主体/项目创建独立本地 bare 仓库，正式资产与候选分别使用 main 和 learning。对象准备完再比较并更新引用；冲突时重读，不自动合并内容，也不靠进程内锁假装跨进程事务。人工回退创建新提交，保留历史。

Git 的引用原子更新不等于 Git 与应用事件库之间有同一个事务。两边确认必须分别对待；提交已完成但事件确认失败时，先核对当前 Git 版本，不能把相同发布盲目重做。物理历史保留和服务端逻辑撤回也是两件独立的事。
