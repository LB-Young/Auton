# Laya Python 运行时：本地接入笔记

- 原链接：[Laya 0.3.20 包版本](https://pypi.org/project/laya/0.3.20/)
- 查阅：2026-11-17；本文为基于固定 wheel 源码检查与本机运行的理解。

该版本支持直接从已有目录加载 Agent。Auton 固定多语言权重并校验摘要，在独立 Python 进程中设置离线模式，仅读取 safetensors、encoder 与 tokenizer。应用启动不自动下载，下载是显式 Python 命令。未使用库的自动语言 Router，避免把“主判断来源固定为 Laya”变成多个 checkpoint 的自动选择。

固定版本将状态和问题/选项拼在同一长度预算内。长状态以及过长选项可能被裁剪，因此适配器在真实 tokenizer 上核对预算，放不下就返回弃权。超时或取消终止本次拥有的进程；重新加载也不会切换到托管模型。没有把子进程隔离称为操作系统安全沙箱。

本机验证只说明模型可运行。六条手工开发样例中，执行档位和信息充分性各正确三条。高分误判保留下来，自动采用保持关闭。后续必须使用独立轨迹标签与保留测试集训练/评估，不能用模型分数自证正确。
