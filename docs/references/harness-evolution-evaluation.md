## 核心观点

自动修改 Harness 的收益，需要排除额外搜索预算和评测数据泄漏的影响。

## 机制与证据

- 在相近反馈与推理预算下，与简单的 test-time scaling / discovery 基线比较。
- 将搜索使用的任务与最终评测任务分离，检验未见任务上的泛化。
- 作者在 Terminal-Bench 2.1 上未发现自动 Harness 进化超过简单推理扩展；部分长周期游戏中则有收益。

## 对 Auton 的启示（待验证）

- §6、§7.5：加入旧版本、旧版本增加重试、新版本三组对照；另行核算候选生成与离线评测成本。
- §7.7：发布依据应包含未见任务收益，不能只看参与候选搜索的用例。

## 局限

结果依赖任务和预算设置，不能据此断言所有 Harness 进化都无效。本文没有验证 Auton 的个人长期使用场景。
