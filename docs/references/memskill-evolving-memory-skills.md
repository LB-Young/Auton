## 核心观点

不仅记忆内容可以更新，提取、整合和裁剪记忆的操作也可以作为技能学习和进化。

## 机制与证据

- controller 选择相关记忆技能，executor 执行技能并产出记忆。
- designer 周期性检查困难案例，修订或新增记忆技能。
- 论文在 LoCoMo、LongMemEval、HotpotQA 和 ALFWorld 上评测。

## 对 Auton 的启示（待验证）

- §4、§7.4：将 LearningCurator 的提取与整合提示作为潜在可进化资产，并单独记录版本。
- §8.1：来源追踪、权限、删除规则与评测隔离仍应由固定治理层约束。
- §6：分别验证记忆处理技能的收益和最终任务收益，避免只优化记忆文本质量。

## 局限

该方法包含可学习的技能选择策略；不能把其整体收益直接归因于纯提示修改，也不能视为现有 Auton 已实现的能力。
