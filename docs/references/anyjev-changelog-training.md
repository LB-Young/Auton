# AnyJev 变更记录：不要依赖已移除的训练接口

- 原文：[AnyJev CHANGELOG](https://github.com/nokia-applied-research/AnyJev/blob/main/CHANGELOG.md)
- 来源：项目维护者；查阅：2026-11-16。
- 本文为中文理解笔记，非原文转载。

## 来源要点

变更记录的 v0.3.0 条目移除了旧版部分标注学习与路由功能，包括过去的 L1/L2 及相关拟合接口，同时引入 Tacit 推理路线。另有概率读取失败时显式报错的修正，避免缺失标签 logprob 被常数替代而产生错误信心。

## 我的理解与 Auton 设计推论

“支持本地决策”与“具备适合用户数据的持续训练器”是两项能力。不能把旧教程中的 `observe`、`fit_head` 或 calibration 示例直接当当前设计的实现依据。锁定版本后，分别验收推理、样本导出、训练、权重恢复和校准。

如果需要旧训练功能，应把旧版作为单独候选，核对维护与相容性，不能混用新旧 API；如果采用当前版，则明确由 Auton 的外部 Training Adapter 承担训练。

## 局限与验证

变更记录描述接口演变，不能替代实际执行验证。接入时保留 commit 和依赖锁，做最小读出实验，检查选项概率完整性、顺序敏感性和错误行为。依赖升级必须重新评测，而非静默追随 latest。
