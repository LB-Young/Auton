## 核心观点

持续在线和主动工作的 Agent 仍有开放问题，包括通知尺度、记忆取舍、异步结果回流、长期目标保持和浏览器交互。文章没有宣称已有统一方案。

## 关键机制与做法

- 后台任务需要在主 Agent 运行、结束或等待审批时正确唤醒。
- 长期目标还可能诱导系统过度优化指标。

## 我的理解

我的理解是常驻助手不只是把普通 Agent 放进定时循环。它需要可持续目标、事件消费、打扰策略以及用户随时修订的控制面。

## 对 Auton 的启示

- 心跳按变化与行动价值通知，相同无变化状态静默。
- 异步结果带目标版本，等待审批时不得因为子任务完成自动绕过批准。

## 局限与适用前提

这是一篇问题展望，不能把其中讨论的方向写成已经解决或经过实证的默认机制。

## 建议验证（尚未执行）

模拟主会话运行、结束和待审批三种状态下的子结果回流，以及长时间无变化心跳。
