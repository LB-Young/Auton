# Vite：前端开发与构建工具

- 原文：[Vite Getting Started](https://vite.dev/guide/)
- 来源：Vite 官方文档；查阅：2026-11-16。
- 本文为中文理解笔记，非原文转载。

## 来源要点

Vite 提供开发服务器、前端开发体验和生产构建能力，支持按框架建立工程。开发环境和生产构建的配置、浏览器支持需要分别理解。

## 我的理解与 Auton 推论

本项目首期可以使用 React/TypeScript 前端工程配合 Python API，开发时配置明确代理与来源，生产由选定服务方式提供静态资源。工具只承担开发/构建，不替代业务后端。

M01 固定 Node、包管理器、依赖版本与 lockfile；README 和 CI 使用同一套命令。前端环境变量不是秘密容器，不应将 provider key 打包到浏览器。

## 局限与验证

支持某框架不等于已选择本项目的路由、状态或组件库。具体稳定版本和浏览器目标在搭框架时核对，不能从旧脚手架模板假设相容。先验证干净安装、开发启动和生产构建，再增量增加依赖。
