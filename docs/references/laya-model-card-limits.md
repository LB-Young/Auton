# Laya 模型卡：权重与适用边界

- 原文：[convaiinnovations/laya 模型卡](https://huggingface.co/convaiinnovations/laya)
- 来源：模型发布者；查阅：2026-11-16。
- 本文为中文理解笔记，非原文转载。

## 来源要点

模型卡标注 Apache-2.0，区分英语、多语言与类型化决策 checkpoint。根版本为约 421M 的英语模型，默认总长度 512；多语言版本约 322M，默认长度 1024。卡片披露零样本、选项预算、评分质量和校准等限制，部分基础模型判断接近随机。

## 我的理解与 Auton 设计推论

不能用“小、快、结构化”推断它已适合中文 Agent。长 trajectory 留给 reviewer；student 只输入决策时真正可见的短状态。状态摘要若用于部署，也必须在数据回放时按同样版本生成，不能用后验总结泄漏答案。

默认长度包括问题和选项，不是全部能用于历史。应按真实 tokenizer 测总预算，尤其多选项任务；截断丢失关键约束时拒绝该样本或改用其他候选。

## 局限与验证

encoder 理论长度上限不等于该 checkpoint 在长状态下有效。中文、多选项、选项重排、分布外问题和概率校准需要分别评测。不要把卡片中的 `act_probability` 当可靠弃权信号，也不要复制作者跨模型分数作为本项目选型结论。
