# 影子与灰度：观察输出和采用输出是两件事

- 原文：[Seldon Core 2 — Concepts](https://docs.seldon.ai/seldon-core-2/about/concepts)
- 来源：Seldon 官方文档；查阅：2026-11-16。
- 本文为中文理解笔记，非原文转载。

## 来源要点

官方概念说明包含模型实验及发布用途：canary 将一部分请求交给候选，shadow 在不影响生产流程的情况下评估候选。平台还强调版本化模型、数据流及监控。

## 我的理解与 Auton 推论

本地决策模型先 shadow，只保存预测，不能改变工具或任务动作。通过判断评估后，才考虑让限定范围的真实任务采用本地结果。Agent 有历史依赖，因此实验分组更适合固定到 goal，而非每个回合重新随机。

主组与影子可以都推理，但只有主组能执行副作用。灰度采用的是发布版本实验，不是按难度动态路由。失败回退也要恢复输入构建、schema 与校准配置，而不只换一个模型文件。

## 局限与建议验证

平台支持部署实验不意味着自动解决 Agent 的因果归因、共享记忆污染或外部写重放。Auton 需自己定义样本量、扩量门槛、任务验收与安全 checkpoint；不必为了这些概念安装 Seldon。
