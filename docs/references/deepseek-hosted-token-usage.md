# DeepSeek 云端 token 用量：本地预算与实际结算

整理日期：2026-11-18。本文为理解笔记。

原链接：[DeepSeek 官方 token 用量说明](https://api-docs.deepseek.com/quick_start/token_usage/)。

## 我的理解

本地 tokenizer 用于请求发出前的输入预算，服务返回的 usage 用于实际用量核对。二者解决的问题不同：本地没有服务端所有隐式处理，云端返回用量则发生在请求执行后。不能因为某次计数吻合，就省略安全余量或把本地估计当成已结算费用。

公开的通用 tokenizer 示例未必绑定正在使用的模型模板。Auton 为 Flash V4.1、Pro V4 分别固定编码资源；准入同时取本地计数加远程余量与原网关保守字节预留的较大值。界面分开显示这两个数，避免用户误认为字节预算是真实 token。

## 对后续开发的约束

M09 发出请求前仍由 M04 做权限、预算和模型能力检查。M08 的 ready 只说明本次装配检查通过，不授予工具权限，不预付或保留预算，不证明模型已执行。实际 usage 和模型 fingerprint 仍由执行结果记录；失败或未知结果不能编造已结算数据。
