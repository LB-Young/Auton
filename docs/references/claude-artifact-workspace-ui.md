# Claude Artifacts：围绕产物继续对话

- 原文：[Claude Artifacts](https://claude.com/features/artifacts)
- 来源：Anthropic 官方产品页面；查阅：2026-11-16。
- 本文为中文理解笔记，不转载原文或复制品牌界面。

## 来源要点

官方将文档、设计和其他产物作为对话中的持续工作对象，用户可以围绕结果迭代、编辑和导出。它体现了聊天与产物工作空间协作的交互方向，而非只产生一段一次性回复。

## 我的理解与 Auton 推论

Auton 应把报告、代码差异、文件与验收证据从长聊天中提取为可定位的对象。主对话表达目标与进展，按需展开的工作面板查看产物、版本和来源；用户继续提要求时要明确作用于哪个版本。

侧栏中的“已生成”和“已验证/提交”必须有不同状态。可预览的产物不等于可以自动执行其中的代码；HTML、附件和工具输出仍是未信任内容。

## 局限与验证

官方产品页不提供 Auton 的 API、数据模型或安全方案。三栏布局、任务轨迹与审批都是本项目设计推论，不能归因于 Claude 已有相同实现。M01 验证面板交互，M06/M12 接入授权产物读取与受限预览。
