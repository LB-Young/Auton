# 神经网络概率校准：高置信不等于高正确率

- 原文：[On Calibration of Modern Neural Networks](https://arxiv.org/abs/1706.04599)
- 作者：Chuan Guo、Geoff Pleiss、Yu Sun、Kilian Q. Weinberger；ICML 2017。
- 查阅：2026-11-16；本文为中文理解笔记，非原文转载。

## 来源要点

论文研究神经网络预测概率与实际正确率不相符的问题，比较校准方法，并发现温度缩放在其多个实验数据集上有效。研究对象包括图像和文档分类；其结论不是对所有 Agent 决策分布的保证。

## 我的理解与 Auton 推论

训练后的本地决策模型即使分类准确率提高，也可能在错误答案上更有信心。评测应同时报告准确率、概率质量及风险—覆盖关系；“只在高置信时回答”仍需要在独立数据上验证。不能把 teacher 的 confidence 直接当训练正确率目标。

校准器在专用开发集合拟合，随模型 bundle 一起版本化。实际量化和新数据分布可能改变校准，不能沿用另一个 checkpoint 的温度。

## 局限与建议验证

ECE 对分箱与样本量敏感，需配合可靠性图、Brier/NLL 和分组错误观察。温度缩放不修复类别选错，也不自动识别分布外任务。稀有严重错误应单独计数并报告证据量。
