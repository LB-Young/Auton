# DeepSeek Chat Completions：流式协议理解笔记

- 原链接：[官方接口文档](https://api-docs.deepseek.com/api/create-chat-completion/)
- 查阅：2026-11-17；本文为工程理解，不是原文转载。

Auton 使用 HTTP SSE。内容可以先到，完成条件仍需结束原因、usage 与 DONE；收到部分文本不能判定成功。usage 可以位于最后一个内容块，也可能单独到达，因此解析器不能只支持其中一种形态。

工具参数是增量 JSON 字符串，需要按 index 拼接，再核对工具名和本次注册的 schema。协议通过不等于工具已执行，M04 不运行任何工具。JSON 模式也要在本地解析，不能仅依靠请求参数保证正确。

短基线显式关闭 thinking，避免默认推理消耗干扰协议验证。生产 Agent 的推理策略另行设计。未知断流不能自动重试：先保存结果、结算、再发布完成事件；已派发但没有完整结果的记录保留未知状态。

这些是本项目的保守实现选择，不代表供应商提供幂等执行或端到端事务。
