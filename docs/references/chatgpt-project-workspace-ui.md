# ChatGPT Projects：按项目组织对话与资料

- 来源：OpenAI 官方帮助文档；查阅：2026-11-16。
- 本文为中文理解笔记，不转载原文或复制品牌界面。

## 来源要点

Projects 将相关聊天、文件和说明放在一个工作空间，通过侧栏项目入口组织长期工作。资料和项目说明为该项目下的工作提供上下文；具体可用范围受产品设置等条件影响。

## 我的理解与 Auton 推论

Auton 的导航应围绕用户项目与会话组织，而非一开始展示全部技术模块。项目资料、说明与会话存在明确归属，用户能看出当前在哪个项目里工作。项目边界也应影响后端检索与授权，不能只在侧栏做视觉分组。

建议左侧项目/最近会话、中央任务对话，设置与学习工作区单独进入。当前任务的模型来源和状态按需展示，不强迫用户理解所有内部工厂。

## 局限与验证

本文借鉴信息组织，不声称完整复刻 ChatGPT 当前页面。Auton 尚需自行设计运行状态、审批、轨迹与训练页面；使用项目分组不能替代真实的数据隔离。M01 验证导航骨架，后续验证真实资料权限和恢复行为。
